## Pickle-Bot - Reference Implementation
- **URL:** https://github.com/thepwizard/pickle-bot
- **Category:** AI Agent / OpenClaw Reference
- **Added:** 2026-03-16
- **Via:** Rajat
- **Related:** Companion to "Build Your Own OpenClaw" tutorial

**Summary:**
A lightweight OpenClaw implementation named after the author's cat Pickle. Features:
- Multi-Agent AI (create specialized agents like Pickle for chat, Cookie for memories)
- Web Tools (search, read pages, research)
- Skills via markdown files
- Cron jobs & scheduled tasks
- Memory system across conversations
- Multi-platform: CLI, Telegram, Discord
- HTTP API

Install: `pip install pickle-bot` or `uv sync` from source.
