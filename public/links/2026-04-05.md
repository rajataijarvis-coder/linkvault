## DeepEval - LLM Evaluation Framework
- **URL:** https://github.com/confident-ai/deepeval
- **Category:** AI/ML, LLM Evaluation, Testing
- **Description:** Open-source Python framework for evaluating LLM outputs. Similar to Pytest but specialized for unit testing LLM apps. Supports metrics like G-Eval, RAG metrics (Answer Relevancy, Faithfulness, Contextual Precision), Agent metrics (Task Completion, Tool Correctness), and more.
- **Key Features:**
  - 30+ ready-to-use evaluation metrics
  - LLM-as-a-judge with human-like accuracy
  - Component-level and end-to-end evaluation
  - Synthetic dataset generation
  - CI/CD integration
  - Works with OpenAI, LangChain, CrewAI, LlamaIndex
- **Language:** Python
- **License:** Apache 2.0
- **Added:** 2026-04-05

## Building AI Agents using AWS Ecosystem - Part 1: Agent Logic SDKs
- **URL:** https://medium.com/@sanjeebmeister/building-ai-agents-using-aws-ecosystem-a-comprehensive-guide-part-1-5de2ed19e579
- **Category:** AI/ML, AWS, Agent Frameworks
- **Description:** Part 1 of a 3-part series on AWS Strands Agents SDK - AWS's open-source SDK for building AI agents powered by Amazon Bedrock and Anthropic Claude. Philosophy: An agent = a model + tools + a prompt. Model-driven approach where the LLM decides when/how to use tools.
- **Key Concepts:**
  - Strands Agents SDK: Simple, model-driven agent framework
  - Agentic Loop: Think → Act → Observe → Repeat
  - Tool definition via @tool decorator on Python functions
  - Built-in tools: file_read, file_write, http_request, shell, retrieve (RAG)
  - Multi-agent patterns: Swarm, Orchestrator, Graph-based
  - Observability: OpenTelemetry tracing, structured logging
  - State & Memory: Conversation history, session persistence
  - MCP Support: Connect to any Model Context Protocol server
  - AWS Native Deployment: Lambda, ECS/Fargate, EC2, Bedrock Agent Runtime
- **Series:** Part 1 of 3 (Agent Logic SDKs → Runtime Infrastructure → Agent Services)
- **Language:** Python
- **Added:** 2026-04-05

## Addy Osmani Agent Skills
- **URL:** https://github.com/addyosmani/agent-skills
- **Category:** AI Agents, Engineering Practices, Developer Tools
- **Description:** Production-grade engineering skills for AI coding agents. 19 structured workflows covering the full development lifecycle: Define → Plan → Build → Verify → Review → Ship. Encodes senior engineer judgment into agent-followable processes.
- **7 Slash Commands:**
  - `/spec` - Spec before code (PRD with objectives, structure, testing, boundaries)
  - `/plan` - Small, atomic tasks with acceptance criteria
  - `/build` - One slice at a time (thin vertical slices)
  - `/test` - Tests are proof (red-green-refactor, test pyramid 80/15/5)
  - `/review` - Code review before merge (five-axis review, ~100 line changes)
  - `/code-simplify` - Clarity over cleverness (Chesterton's Fence, Rule of 500)
  - `/ship` - Faster is safer (feature flags, staged rollouts, rollback)
- **19 Skills Include:**
  - **Define:** idea-refine, spec-driven-development
  - **Plan:** planning-and-task-breakdown
  - **Build:** incremental-implementation, context-engineering, frontend-ui-engineering, api-and-interface-design
  - **Verify:** test-driven-development, browser-testing-with-devtools, debugging-and-error-recovery
  - **Review:** code-review-and-quality, code-simplification, security-and-hardening, performance-optimization
  - **Ship:** git-workflow-and-versioning, ci-cd-and-automation, deprecation-and-migration, documentation-and-adrs, shipping-and-launch
- **3 Specialist Agents:** code-reviewer (Staff Engineer), test-engineer (QA), security-auditor
- **Key Principles:**
  - Process, not prose (workflows with checkpoints, not reference docs)
  - Anti-rationalization (common excuses + rebuttals)
  - Verification is non-negotiable (evidence requirements)
  - Progressive disclosure (supporting refs load only when needed)
- **Google Engineering Influence:** Hyrum's Law, Beyonce Rule, test pyramid, trunk-based dev, Shift Left
- **Platforms:** Claude Code (plugin), Cursor (.cursor/rules), Windsurf, GitHub Copilot, Codex
- **License:** MIT
- **Added:** 2026-04-05
