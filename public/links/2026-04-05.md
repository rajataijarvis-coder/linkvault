## DeepEval - LLM Evaluation Framework
- **URL:** https://github.com/confident-ai/deepeval
- **Category:** AI/ML, LLM Evaluation, Testing
- **Description:** Open-source Python framework for evaluating LLM outputs. Similar to Pytest but specialized for unit testing LLM apps. Supports metrics like G-Eval, RAG metrics (Answer Relevancy, Faithfulness, Contextual Precision), Agent metrics (Task Completion, Tool Correctness), and more.
- **Key Features:**
  - 30+ ready-to-use evaluation metrics
  - LLM-as-a-judge with human-like accuracy
  - Component-level and end-to-end evaluation
  - Synthetic dataset generation
  - CI/CD integration
  - Works with OpenAI, LangChain, CrewAI, LlamaIndex
- **Language:** Python
- **License:** Apache 2.0
- **Added:** 2026-04-05
