## Mini OpenClaw - Reference Implementation
- **URL:** https://gist.github.com/dabit3/86ee04a1c02c839409a02b20fe99a492
- **Author:** Nader Dabit (dabit3)
- **Type:** Code Reference / Implementation
- **Tags:** #openclaw #python #reference-implementation #code
- **Summary:** The actual ~400 line "mini-openclaw.py" implementation that accompanies the architecture tutorial. Features: dual-agent setup (Jarvis + Scout researcher), 5 tools (run_command, read_file, write_file, save_memory, memory_search), permission system with approval allowlist, JSONL session persistence, automatic context compaction, heartbeat/cron scheduling, per-session threading locks. Self-contained runnable with `uv run --with anthropic --with schedule python mini-openclaw.py`.
