# OpenDataLoader PDF

**URL:** https://github.com/opendataloader-project/opendataloader-pdf  
**Added:** 2026-04-08  
**Category:** AI/ML, PDF Processing, Data Extraction

## What It Is

The **#1 ranked PDF parser** for AI-ready data extraction. Converts PDFs to:
- **Markdown** (for LLM ingestion)
- **JSON** (with bounding boxes for source citations)
- **HTML** (preserving structure)

## Key Features

- **Benchmark #1:** 0.907 overall accuracy (vs docling 0.882, marker 0.861)
- **Table extraction:** Complex/borderless tables (0.928 accuracy)
- **OCR built-in:** 80+ languages for scanned PDFs
- **Hybrid mode:** Local + AI for complex pages
- **LaTeX formulas:** Mathematical expression extraction
- **Image descriptions:** AI-generated chart/picture descriptions
- **Reading order:** XY-Cut++ algorithm preserves document flow

## Installation

```bash
# Requires Java 11+ and Python 3.10+
pip install -U opendataloader-pdf

# For hybrid mode (AI-powered complex extraction)
pip install "opendataloader-pdf[hybrid]"
```

## Quick Usage

```python
import opendataloader_pdf

# Convert PDF to markdown + JSON
opendataloader_pdf.convert(
    input_path=["document.pdf"],
    output_dir="output/",
    format="markdown,json"
)
```

## Hybrid Mode (For Complex PDFs)

```bash
# Start hybrid server
opendataloader-pdf-hybrid --port 5002

# Extract with AI assistance
opendataloader-pdf --hybrid docling-fast document.pdf
```
