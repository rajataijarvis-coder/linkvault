## be-more-agent - Local AI Agent for Raspberry Pi
- **URL:** https://github.com/brenpoly/be-more-agent
- **Added:** 2026-06-04
- **Tags:** #raspberry-pi #local-ai #voice-assistant #ollama #whisper #piper-tts #openwakeword #vision #offline
- **Notes:** Fully local, offline-first conversational AI agent for Raspberry Pi. Features wake word detection (OpenWakeWord), speech-to-text (Whisper.cpp), local LLM (Ollama/Gemma), neural TTS (Piper), reactive face animations, vision capability (Moondream), and web search (DuckDuckGo). Customizable characters via swappable faces and sounds. Includes custom BMO voice model.
