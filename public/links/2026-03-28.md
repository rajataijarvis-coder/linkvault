# Link Added: PI Coding Agent by Mario Zechner (Creator)

**Source:** mariozechner.at  
**Date:** 2026-03-28  
**Topic:** PI Coding Agent Design Philosophy  
**URL:** https://mariozechner.at/posts/2025-11-30-pi-coding-agent/

## Summary
From the creator of PI/OpenClaw himself: "What I learned building an opinionated and minimal coding agent"

## Key Insights
- **Minimal philosophy**: Rejects feature creep (Claude Code became "a spaceship with 80% of functionality I have no use for")
- **Four APIs**: pi-ai, pi-agent-core, pi-tui, pi-coding-agent
- **Multi-model world**: Context handoff between models
- **YOLO by default**: No built-in to-dos, no plan mode
- **Intentionally minimal**: No MCP support, no background bash, no sub-agents

## Design Philosophy
- Simple, predictable tools
- Structured split tool results
- Retained mode UI with differential rendering
- Minimal system prompt, minimal toolset

## Why It Matters
This is the **source of truth** - the creator's own reasoning behind OpenClaw/PI architecture.

# Link Added: LangChain Agent Harness Anatomy

**Source:** blog.langchain.com  
**Date:** 2026-03-28  
**Topic:** Agent Harness Architecture  
**URL:** https://blog.langchain.com/the-anatomy-of-an-agent-harness/

## Summary
LangChain's framework for understanding agent architecture:
- **Agent = Model + Harness**
- **Harness** = everything that isn't the model: system prompts, tools, infrastructure, orchestration, hooks/middleware
- **Model** = intelligence
- **Harness** = makes intelligence useful

## Key Components
- System Prompts
- Tools, Skills, MCPs + descriptions
- Infrastructure (filesystem, sandbox, browser)
- Orchestration Logic (subagent spawning, handoffs, model routing)
- Hooks/Middleware (compaction, continuation, lint checks)

## Why It Matters
This is a foundational mental model for agent architecture - highly relevant to OpenClaw's design patterns.
