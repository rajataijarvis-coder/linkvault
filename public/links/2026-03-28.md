## Summary

## Key Architectural Insights

### 1. Monorepo Structure (8 Packages, 3 Layers)
- **Foundation**: Zero internal dependencies
- **Core**: Depends only on foundation
- **Applications**: Sit on top
- Strict dependency graph enforced at build time

### 2. LLM Abstraction Layer (pi-ai)
Normalizes **4 wire protocols**:
- OpenAI Completions (`/v1/chat/completions`)
- OpenAI Responses (`/v1/responses`)
- Anthropic Messages (`/v1/messages`)
- Google Generative AI (`/v1beta/models/{model}:generateContent`)

**Model catalog**: 300+ definitions auto-generated from models.dev + OpenRouter

### 3. Provider Quirk Handling
Abstracts provider-specific differences:
- Cerebras: no `store` field
- Mistral: `max_tokens` vs `max_completion_tokens`
- Google: no tool call streaming
- Anthropic: reasoning in `thinking` blocks
- xAI: specific header handling
- Groq: rate limit backoff

### 4. Tool Definition (TypeBox + AJV)
- JSON Schema validation
- Validation errors returned to model for self-correction
- Eliminates runtime failures

### 5. Context Portability
- Fully serializable
- Portable across providers
- Enables session persistence
