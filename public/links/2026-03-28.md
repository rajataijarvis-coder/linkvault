## Summary
An AI assistant that lives in your browser sidebar. Built for collaboration, not autonomy theater.

## Key Features
- Chrome/Edge extension side panel
- Automate repetitive web tasks
- Extract data from any website
- Navigate across pages, fill forms
- Compare products, compile research
- Transform findings into documents/spreadsheets

## Technical Stack
- Built on **PI-mono** (Mario's agent framework)
- Uses **mini-lit** for UI components
- Supports multiple AI providers (Claude, OpenAI, Copilot, Gemini)

## Philosophy
- "You guide, it executes" (human-in-the-loop)
- Collaboration over autonomy
- Data stays on machine (privacy-first)
